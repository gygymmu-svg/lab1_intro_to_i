Алгоритм Программы №1 (Сотрудники):
Начало.

Объявление класса Employee с полями: имя, должность, зарплата.

Определение методов ввода (inputData) и вывода (displayInfo).

В главной функции main запрос у пользователя количества сотрудников.

Динамическое выделение памяти под массив объектов класса Employee.

Циклический ввод данных для каждого объекта в массиве.

Инициализация переменной highestPaid первым элементом массива для поиска максимума.

Перебор массива в цикле: если текущая зарплата больше, чем у highestPaid, обновить значение highestPaid.

Вывод информации о найденном сотруднике на экран.

Освобождение динамической памяти.

Конец.

Алгоритм Программы №2 (Студенты):
Начало.

Описание класса Student для хранения данных о студенте и его успеваемости.

Реализация метода input для получения данных с клавиатуры.

В функции main инициализация массива объектов Student.

Заполнение массива данными через цикл (количество итераций задает пользователь).

Вывод заголовка таблицы для итогового отчета.

Запуск цикла по массиву студентов для фильтрации.

Проверка условия: если средний балл объекта больше 4.5, вызвать метод printRow для отображения строки данных.
